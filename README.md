# PassForge

PassForge is a simple and customizable password generator built with React and TypeScript. It allows users to generate secure passwords based on their preferred length and character options, including uppercase letters, lowercase letters, numbers, and symbols.

The project focuses on providing a clean, intuitive, and practical experience for quickly creating strong and customizable passwords.

## Features

- Generate secure passwords
- Customize password length
- Include uppercase and lowercase letters
- Include numbers and symbols
- Copy generated passwords to the clipboard

## Tech Stack

- React
- TypeScript
- Vite
- CSS
